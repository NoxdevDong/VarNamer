﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿VarNamer 中文变量取名 · 使用说明（v5.7）
================================================================

【这是什么】
  输入中文，直接得到符合团队规范的英文变量名。
  例：数学成绩 → math_score / MathScore / mathScore …
  共 13 种命名风格：全称 Pascal/camel/snake/SCREAMING_SNAKE/kebab/dot、
  简短（每词≤4）、缩写（每段≤3 / 首字母）等。

【两个版本，装哪个都行】
  · 便携版（VarNamer-Portable-v3.3.zip）
      解压到任意文件夹（U 盘也行），双击 VarNamer.exe 就能用。
      目录里有 portable.txt，所有配置/词库/记录都写在同目录的
      VarNamerData 文件夹里，不写系统盘，删掉文件夹即彻底卸载。
  · 安装版（VarNamer-Setup-v3.3.exe）
      双击运行安装向导：选目录 →勾选项→ 开始安装。
      默认装到当前用户目录（%LOCALAPPDATA%\Programs\VarNamer），
      不需要管理员权限；改成 Program Files 才会请求提权。
      会写入“设置 → 应用 → 已安装的应用”，可直接在那里卸载，
      也可以走开始菜单 → VarNamer → 卸载 VarNamer。
      卸载时可选是否一并删除配置与词库。

【词库：已内置，开箱即用】
  · 约 1.18 万条中英词条（含编程/系统术语）（覆盖 IT/数据/网络/前端/移动/业务/电商/金融/
    教育/医疗/人事/政务/生活/工业/物流 等领域）已编译进主程序，
    打开即可用，不需要任何导入动作。
  · 想自己扩词：把词库文件（.txt）放进下面任一位置，程序启动自动导入：
      1) 程序目录\dict            —— 文件名随便起，这个目录下任意 .txt 都收（推荐）
      2) 程序目录（exe 同级）      —— 文件名要含「词库」或「dict」，或用固定名：
                                     VarNamer-Dict-CN-EN.txt / VarNamer-Dict.txt /
                                     userdict.txt / 词库.txt / dict.txt
    （只扫描程序自己的这两个位置，不去翻其它目录）
    立即生效：词库管理 →「检测本地词库」，会列出扫到的文件和详细结果：
      "文件里 N 条 · 写入用户词库 M 条 · 跳过 K 条"，
      跳过 = 已经在内置词库或你的用户词库里的词条（这些词本来就能用，不需要重复导入）。
      如果检测到的词条全部都已被收录，程序会问你要不要把"全部写进用户词库"
      —— 选"是"就会在词条列表里看到它们（内容和内置重复）。
    格式：中文=英文（# 开头是注释；英文多词用空格；
          同义词用 | 分隔，如 成绩=score|grade；空值=停用词，直接忽略）。
    规则：只做加法。用户词库里已有同名的条目永远不会被覆盖。
    便携版/安装版的目录里都带了一份 dict\VarNamer-Dict-CN-EN.txt，
    内容与内置词库一致，可以直接在这份文件上改。
  · 词库管理分三个标签页：「词条」搜索/增删、「导入导出」检测本地词库+导入导出 txt+备份恢复+打开词库目录、「在线翻译」设置面板（页面上直接开关 + 状态徽章 + 需要什么 + 密钥是否已配置 + 一键配置）。

【热键】
  Ctrl+Alt+V  唤起悬浮窗并自动转换剪贴板内容（可改：主界面 → 选项 → 热键）
              收起悬浮窗：Esc，或主界面「隐藏悬浮窗」，或托盘菜单「显示/隐藏悬浮窗」
  Ctrl+Alt+A  截图标注（可改）

【主界面布局】
  · 左栏：中文输入 + 命名结果（13 种风格按「全称 / 简短 / 缩写」分段，
    灰色小标题行只是分组，不参与复制）
  · 右栏：分词词块 + 选项（分「命名规则 / 操作 / 词库」三组）
  · 「词库」组底部显示：内置 N 条 · 我的词条 M 条，旁边可直接打开词库目录

【重复启动】
  程序是单实例的：再次双击只会把已经打开的窗口弹到前台，不会开第二个。

【主界面的「悬浮窗」按钮】
  显示中时按钮是「隐藏悬浮窗」（高亮），点一下收起；隐藏后变成「显示悬浮窗」，再点一下唤出。
  状态和托盘菜单 / 热键 / 悬浮窗自己的关闭按钮实时同步。

【悬浮窗怎么用】
  · 刚打开/输入框为空时：窗口只有一条输入框（不会显示任何候选行）
  · 输入中文后再展开结果行；上方有风格切换条：混合 / 全称 / 简短 / 缩写
  · **中英双向**：输入中文出英文变量名；输入纯英文会额外给一行「中文」，反查对应的中文词
    （如 name → 名字、score → 分数；整句命中给整词：user_name → 用户名；没有整词时逐词组合：用户 + 名字）
    （混合=变量/类/常量/简短/缩写，随「目标语言」预设；其余三组只看该组写法，窗口高度自动跟随）
  · 点结果行 = 复制；回车 = 复制第一行；清空输入 = 窗口收回最简状态
  · 默认半透明（不挡视线）：点一下窗口 / 开始输入 → 全亮；点到别处 → 自动恢复半透明
  · 窗口淡入、结果行依次亮起、按钮悬停渐变——都是轻量动效，不影响速度
  · Ctrl+滚轮 调透明度（半透明时调"默认透明度"，全亮时调"全亮不透明度"）
  · Esc 隐藏 · 顶部「顶」切换置顶 · 「主」打开主窗口
  · 顶部「缩」把悬浮窗收成一个桌面小挂件（150×38）：**挂件不置顶、压在最底层，不会挡住任何窗口**；点挂件展开（展开后恢复原来的置顶设置），按住可拖动

【截图标注】
  微信风格：框选 → 8 个手柄调选区 → 矩形/椭圆/箭头/画笔/高亮/马赛克/文字 →
  复制、保存，或“钉在桌面”贴成悬浮图（滚轮或拖角等比缩放）。

【数据放在哪】
  便携版：程序目录\VarNamerData\
  安装版：%APPDATA%\VarNamer\（config.ini / userdict.txt / unknowns.txt / history.txt）
  想强制指定：设置环境变量 VARNAMER_DATA_DIR=某个目录。

【常见问题】
  · 双击没反应？可能已经在运行（托盘区找图标）。程序是单实例。
  · 热键和别的软件冲突？主界面 → 选项 → 热键，改一个即可。
  · 未收录的词？主界面“未收录记录”里能看到，可一键补进词库。
  · 在线翻译（可选）默认关闭，需要自己在设置里填百度/有道等平台的
    密钥；不使用也不影响任何本地功能。
